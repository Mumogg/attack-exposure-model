# Notas de laboratorio

Atomic Red Team y MITRE CALDERA se utilizan **fuera de este repositorio**, en un laboratorio aislado, para contrastar el comportamiento de técnicas concretas. Este repositorio **no** contiene, descarga ni ejecuta código ofensivo: solo analiza texto y datos estructurados.

Si en el futuro se documentan resultados del laboratorio, deben registrarse aquí como notas (fecha, técnica, observación), sin incluir cargas útiles ni scripts.
